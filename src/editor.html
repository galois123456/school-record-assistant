암호화 백업 안내

JSON 백업은 12자 이상의 별도 비밀번호로 암호화합니다. 비밀번호를 두 번 입력하고 ‘암호화 준비’ → ‘암호화 JSON 저장’을 누르세요. 복원할 때 같은 비밀번호가 필요합니다. 비밀번호를 잊으면 복구할 수 없습니다. 로그인 비밀번호와 다르며 프로그램에 보관하지 않습니다.

공통 명단에서 모든 반의 학생을 관리합니다. 여러 행을 수정한 뒤 전체 저장을 누르세요. 상단 공통 반을 선택하면 네 화면이 같은 반으로 바뀝니다.

학생 누가기록: 날짜와 내용을 입력하고 기록 저장. 학생 이름 옆 ‘누가기록 전체 보기’에서 날짜별 또는 참고자료 형태로 선택 학생의 전체 기록을 볼 수 있습니다. 스탬프는 항목별 ＋/−로 증감하며 음수도 허용합니다. 증감 이력의 취소로 실수를 되돌릴 수 있습니다. 항목 관리에서 이름을 변경하거나 추가하세요.

교과 활동 통합 관리: 활동 관리 → 활동별 작성 → 활동 일괄 합치기. 통합 생기부 행은 모두 숨기거나 펼칠 수 있습니다.

문장 매크로 생성기: 상단 공통 반의 학생에게 문장 양식을 적용합니다. {학생이름|은는}처럼 쓰면 조사를 자동 선택합니다. 발음이 불분명하면 안내가 표시되며 변수 설정의 발음 사전으로 보완합니다. 동사·형용사 활용과 문장 의미는 최종 검토가 필요합니다. 문장 양식은 반과 다른 개념이며 각 양식이 같은 공통 명단을 사용합니다.

활동 보조 관리: 여러 항목을 모아 카테고리로 저장합니다. 종합은 기존 양식이며 국어·영어·수학·사회·과학 예시가 제공됩니다. 카테고리를 전환하면 해당 카테고리의 학생 기록도 함께 바뀝니다. 새 카테고리·양식 복사·이름 변경·삭제를 지원합니다. 항목 양식 CSV는 새 카테고리로 가져옵니다. 내보내기는 선택한 카테고리 기준이며 모든 카테고리 보존은 통합 백업을 사용하세요.

입력칸 높이: 기존 도구 줄의 입력칸 높이 버튼을 눌러 좁게·보통·넓게 또는 슬라이더로 조절하세요. 학생 누가기록은 입력창 위에서 바로 조절합니다. 내용에 맞춤을 선택하면 길이에 따라 늘어납니다. 화면별 설정은 자동 저장되며 통합 백업에도 포함됩니다. 모바일에서는 세로 배치와 카드형 입력으로 같은 주요 기능을 사용합니다.

전체 설정에서 통합 백업·복원, 공통 옵션과 초기화를 관리합니다. 이전 ver2.01·2.02 통합 백업을 불러올 수 있습니다. 기록은 현재 브라우저에 자동 저장되므로 정기적으로 통합 백업하세요. 자료를 AI로 자동 전송하지 않습니다.

학생·반 삭제는 네 화면의 해당 기록도 삭제합니다. 삭제·초기화 전 백업으로 복원할 수 있습니다. 스탬프는 교사의 관찰 보조 자료이며 그대로 공식 평가 결과를 뜻하지 않습니다.
