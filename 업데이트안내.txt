웹 ver3.02 · 활동 보조 관리 펼침 유지 및 PC 상단 통합

- 활동 보조 관리에서 점수·태그 선택 등으로 화면이 다시 그려져도 항목별 펼침 상태를 유지합니다.
- PC의 CLOUD·서버 저장 상태를 제목 오른쪽으로 옮겼습니다.
- PC의 로그인 이메일을 공통 명단 왼쪽, 저장·서버 새로 열기·로그아웃을 전체 설정 오른쪽에 배치했습니다.
- 편집기가 준비되면 PC의 별도 Cloud 줄을 숨깁니다. 모바일과 초기 로딩 화면은 기존 줄을 사용합니다.
- 기존 주황색 아이콘과 기능은 유지됩니다.

1. 기존 사이트에서 통합 백업을 한 번 받아 두세요.
2. school-record-assistant 폴더 안의 파일과 폴더를 기존 GitHub 저장소 루트에 덮어 올리세요. 폴더 자체를 한 단계 안에 넣지 마세요.
3. 커밋 후 기존 Vercel 프로젝트에서 자동 배포가 완료되면 같은 주소로 접속하세요.
4. 기존 환경변수와 Supabase 프로젝트를 그대로 사용합니다. SQL 재실행은 필요 없습니다.
5. 브라우저 탭용 SVG, iPhone/iPad용 PNG, 홈 화면용 192/512 PNG와 manifest를 포함했습니다.
6. 홈 화면의 기존 아이콘이 유지되면 바로가기를 제거하고 사이트에서 다시 홈 화면에 추가하세요.

오프라인 편집 기능은 추가하지 않았습니다. 로그인과 서버 저장에는 인터넷 연결이 필요합니다.
